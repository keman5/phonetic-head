# 英语教学路径审查

本次以现有 `phonemes.js`、`learning.js`、`audio.js`、`generate-audio.py` 为依据；不把静态代码审查当成实际课堂观察或专业发音认证。

| 发现 | 学习影响 | 本次处理与验收 |
| --- | --- | --- |
| 只有单音、字母名和字母表连播，没有从声音进入语言意义的路径 | 学生能模仿单音，但缺少在词句中运用的入口 | 增加四组固定的「字母音 → 单词 → 短语 → 句子」，每步有中文释义和操作提示 |
| 字母名与词中音值是不同目标，原字母名 D 的序列为 /diː/ | 把字母名带进 dog 会多出一个元音；C 还可能被误教为始终 /s/ | 每组明确字母名与目标词音值，例如 C 名称 /siː/，cat 的 c 是 /k/；字母音关卡只使用目标音素 |
| 长句不能只把单音等时拼接视为自然朗读 | 忽略弱读、词边界及韵律，模型可能造成过强的同步暗示 | 词句保存完整文本、词边界与逐词音素；a 标为 /ə/，句末标示示范重音；合成整句音频，模型时间轴明确为近似示意 |
| 辅音连缀和拼写组合缺少具体迁移提示 | 常出现 /ɡ/、/l/、/k/ 后加元音，或将 sh 拆成两个声音 | 给 big dog、black cat、red fish、cold milk 各自的连接提示，fish 的 sh 对应单音 /ʃ/ |
| 活动完成可能被误解为发音正确 | 三颗星不足以证明发音准确 | 继续沿用 PracticeSession 的活动完成语义，不添加无录音依据的正确率或评分 |

## 具体内容

- d → dog → big dog → This is a big dog.
- c → cat → black cat → This is a black cat.
- f → fish → red fish → This is a red fish.
- m → milk → cold milk → I like cold milk.

界面应始终显示当前教学层级和完整文本；词高亮只帮助跟上当前读到的位置。切换教学目标时，正在播放的音频与原任务进度必须停止或重置。听句子时先听完整示范，再自行跟读；慢速口型观察与自然语速听音应保留各自目的。

## 数据验收和边界

`node --test curriculum.test.mjs` 检查四阶段顺序、目标文本、合法音素、完整词边界、连续时间分段、英式 dog 元音、弱读 a，以及 sh 的音素归并。

当前分段依据现有教学音素时长生成，未做音频强制对齐，不能称为逐帧准确的自然连读；本次没有加入开放式任意文本输入，以免把未校验音素序列变成教材。正式教学前仍需教师审听合成语音的音质、重音和韵律，并观察儿童是否理解提示。3D 接触和气流准确性由模型审查另行验证。
