# 连续英语教学：模型审查与修复

日期：2026-10-16。角色：高级 3D 建模师。

## 已修复

| 问题 | 复现证据 | 最小修复 |
| --- | --- | --- |
| 连续音素的教学阶段跟随整句进度，后面的声音不会重新显示起音阶段 | `timelinePose` 原来用 `s / duration` 计算 `step`。用 `this is a big dog` 的音素序列检查每段起音、保持、收尾，无法匹配当前音素阶段 | 根据当前 clip 计算 `phonemeProgress` 和 `step`；保留 `t` 表示整体进度。单独元音也提供 `phonemeProgress` |
| 鼻音转同部位爆破音时，仍有气流却被切到完全封闭的口腔路径 | `m → b`、`n → d`、`ŋ → g` 的混合区中，唇/舌封闭权重保持 1；原来 `nasal` 直接混合软腭权重，越过 0.5 后渲染器选择口腔路径。例：`m → b` 边界后 0.02 秒，口腔仍封闭，气流仍未归零 | 按实际鼻腔流量占总流量的比例混合 `nasal`，使剩余气流保持鼻腔路径并逐渐消失；`nasal` 不再随全局音量包络衰减，包络只作用于总气流与形变 |

调用点核查覆盖 `motion.js`、`app.js` 的气流与状态显示、`learning.js` 的注意力提示，以及音素与教学测试。`nasal` 仍为 0–1，现表示气流路径比例；软腭运动仍由 `weights.VelumLower` 驱动。另提供 `nextPhoneme`，让教学提示能区分继续连读与结束放松。
