# 儿童音标教学范本 · 本地试用版

## 这一版做了什么

- 不删除或用几何块替换器官。复用原始人头、舌头、软腭、牙齿及24个形变控制；默认隐藏颅骨、颈椎、眼部和鼻腔零碎结构、非必要肌肉。
- 桃色头部、粉色舌头、紫色上腭、青绿色气道、金色声带区域；儿童模式有简单眼神和唇色。颜色只帮助识别，不代表真实组织颜色。
- 儿童模式不显示上颌骨、腭骨等骨骼；牙齿单独保留用于发音参照。硬腭边界用连续紫色色带表示，教师模式仍可恢复参考结构。
- 鼻腔、口腔与气道使用封闭的彩色剖面底层，放在舌头和牙齿后面；外侧轮廓补面盖住填充体的三角阴影。色块表示腔体空间，不表示真实的实心组织，边界是教学简化轮廓。
- 默认侧向剖视。模型上的“软腭、舌头、声带区域”引导标签只在可见侧向剖视中显示；点击可高亮。标签指向参考部位，不是组织运动测量。
- 48个条目都有嘴唇、舌头、气息、声带提示及对照入口；20元音、26字母及连播保持可用。
- “看慢动作→听示范音→我来试试”：观察采用独立无声4秒周期；听音恢复实际音频时钟；自查清单不采集录音，也不提供虚假评分。
- 复杂透明度滑杆折叠进教师工具；结构细节可恢复。保留男女声、0.2–3倍速、暂停、拖动与循环。

## 内容口径

- 使用常见英式44音素教学体系，另列 /ts dz tr dr/ 四组辅音组合；48不是英语音素数量的唯一标准。
- /r/ 使用教材记号，实际示范英语近音 [ɹ]；不弹舌。/ɜː/ 为非卷舌英式示范。
- 长短元音涉及音质与舌位差异，不仅是时间长短；长音标记 ː 不是重音标记 ˈ。
- /ʊə/ 等集中双元音在现代口音中存在变化，课堂应以选定教材与教师采用的口音为准。
- 合成声音是辅助演示，不标为母语教师真人范读，不用男女声作为准确性等级。

## 正式作为标准范本前还要完成

| 优先级 | 问题 | 验收方式 |
| --- | --- | --- |
| P0 | 示范音的音质、重音、清浊及口音需要专业复核 | 选定口音；教师逐项审听单音、例词和短句，明确录音授权；不以合成文件可播放作为标准发音证明 |
| P0 | 部分圆唇姿态仍有唇齿穿插；舌腭/舌齿接触未受碰撞约束 | 逐音观察正面、侧剖、嘴部近景；核对 /uː w f v θ ð t d k g/，修正闭合、摩擦缝隙和释放 |
| P0 | 气流路径仍是示意曲线，未随声道形变进行流体计算，可能与组织投影交叠 | 教师核对口腔/鼻腔出口、闭塞与释放时序；界面明确说明示意，不把粒子轨迹当精确声道 |
| P1 | 人头还是成人底模，面颊和嘴周表面存在源模型褶皱；并非重新雕刻的儿童角色 | 保留内部比例，进一步平滑外表面及优化唇缘拓扑；不要为卡通比例移动内部发音位置 |
| P1 | 重音、弱读、连读和唱歌不等同于单音口型串联 | 增加经核准的单词/短句示例及音素时间对齐，明确主重音/次重音和弱读，不用简单放大音量代替重音 |
| P1 | 儿童是否理解提示、能否轻松模仿尚未做使用测试 | 由教师陪同试用，观察辨认部位、操作负担及错误模仿；避免要求憋气、使劲挤喉咙 |

## 验证与复现

本地服务 `http://127.0.0.1:4173/`，不发布线上。网页材质与简化模式由 `dist/palette.js`、`dist/teaching.js`、`dist/app.js` 控制；原始GLB资产本轮不改写。

运行 `npm test`、`node check-teaching.mjs`、`node check-browser.mjs`、`node check-audio-ui.mjs`、`node check-vowels.mjs`。截图输出在 `qa/`，使用本机安装的Google Chrome。

`build_teaching_preview.py` 另存 `phonetic-head-child-teaching.blend`：保留20个元音时间轴和隐藏的细节参考，增加儿童配色及简单眼神。原始 `phonetic-head-articulated.blend` 不覆盖。网页的动态剖面补面、标签、气流和教学卡是运行时功能，不烘焙进此Blender文件。

自动化验证代表功能链路可用，不代表发音、接触几何或生物力学准确性已经获得认证。
