# 发音探索乐园（本地）

本地访问 http://127.0.0.1:4173/ ，开发服务只绑定本机。线上部署见项目根目录 README，地址为 https://test.upit.top/ 。

## App 式课程流程

首页 `index.html` 是课程选择与学习进度；`learn.html?course=dog` 是独立的分章节课堂；`lab.html` 是教师自由探索的实验室。旧的 `/?lesson=dog-sound` 链接会转入对应课程。浏览器返回、章节回看和刷新均保留当前学习位置。

示范课堂的正面与唇部特写显示完整双侧，右侧与口腔特写显示剖面；重置回到初始右侧剖面。切换视角保留当前示范进度与播放状态，视角按钮提供选中状态和至少 44px 的触摸区域。`classroom-views.test.mjs` 覆盖这些切换及 320/390px 布局。

每课包含七个任务和一页回顾：情境整句听读 → 观察目标音慢动作 → 单词跟读 → 听句子选意思 → 短语练习 → 完整句跟读 → 脱离文字自主表达和自查 → 完课回顾。未完成的下一章节不会提前开放；完整播放、听辨正确或自查分别触发对应完成状态，暂停和拖动不会冒充完整示范。孩子主动点击播放与继续，没有后台自动跳课。

首页不加载三维资产；进入观察/词句章节时才嵌入已有模型，后续章节复用同一个实例。播放器隐藏分类库、解剖参数等教师工具，仅显示教学模型。三维资源不可用时可切换图文与声音；该替代方式使用同一份发音提示和音频。页面切换、返回课程或进入后台会停止旧示范。

课程进度只保存在当前浏览器的 localStorage，不上传、不跨设备同步。完成只表示参与任务，不是自动发音评分。学习时间 5–8 分钟是建议节奏，允许慢慢练习。`journey.test.mjs` 验证存储数据校验，`journey-ui.test.mjs` 通过本机浏览器验证真实音频、模型、答题、刷新续学和移动布局。

前端无需打包，`npm run dev` 通过 `start-app.sh` 启动仅监听本机的 Node 服务（含课程管理与可选 AI 代理）。`admin.html` 可编辑课程、上传或生成示范语音，详细账号、配置与发布流程见根目录 README。以下发音分类与自由练习说明适用于教师实验室。

## 从声音到句子的英语教学

在“学习模式”选择“单词与句子 · 循序跟读”，或直接打开
http://127.0.0.1:4173/lab.html?lesson=dog-sound 。每组都有字母在词中的声音、单词、短语和句子四步：

| 系列 | 单词 | 短语 | 句子 |
| --- | --- | --- | --- |
| d /d/ | dog | big dog | This is a big dog. |
| c /k/ | cat | black cat | This is a black cat. |
| f /f/ | fish | red fish | This is a red fish. |
| m /m/ | milk | cold milk | I like cold milk. |

课程明确区分字母名称（例如 D /diː/）和词中发音 /d/；提供中文释义、弱读和连续辅音提示。
阶段按钮支持方向键、Home/End，播放时逐词高亮。原有暂停、拖动、男女声、倍速、有声慢动作及三步自查均可用于整句；切换课程会停止旧音频并清空本次练习状态。有声慢动作由实际音频进度驱动，声音与口型一起减速。课程不会自动跳到下一阶段；只有主动开始录音或连续语音时才请求麦克风，不自动给发音分。

10 组、40 节课程配有 80 个本地 WAV。单个字母音复用已有音素录音；单词、短语和句子整段合成，不拼接孤立音素。词句使用 Kokoro 英式神经语音；逐词时间使用新模型的时长输出，词内音素按教学比例安排，口型仍是示意而非精确语音对齐。自然朗读与慢速分解可能有不同的协同发音，需教师校准。

课程数据位于 `dist/curriculum.js`；`generate-curriculum-audio.py` 生成基础课程与时间参考，`build.sh natural` 替换字母和词句音源。在本目录执行 `npm run build:lessons` 依次重建，或 `npm run build:audio:natural` 只更新自然语音；运行时无需构建。

`npm test` 包含课程数据、音频校验和、词语时间边界和连读模型测试。先启动本地服务，再执行 `npm run test:ui`，覆盖课程键盘操作、320–1440px 布局、两种声线、暂停/定位、切换中止、完整播放、慢动作和加载失败重试。产品、交互、3D 专项审查分别记录于 `PRODUCT-REVIEW.md`、`INTERACTION-REVIEW.md`、`MODEL-REVIEW.md`。

## 人体素模

网页只提供儿童教学人头，默认儿童简化侧向剖视。眼球、嘴唇与皮肤使用相同素模材质，不再绘制瞳孔或唇色色块。卡通模型入口及加载已移除，历史 Blender/GLB 资产仅保留为源文件备份，不参与网页运行。模型点选显示中文部位名称，不显示皮肤修补网格的内部名称。

## 儿童教学显示

保留真实器官底模，隐藏与发音无关的颅骨、颈椎和肌肉细节；上腭、舌头、气道保留固定区分色及侧向部位标签。教师工具可恢复详细结构及透明度控制，儿童显示不删除源网格。

儿童模式也不绘制上颌骨和腭骨，仅保留独立的牙齿作教学参照。鼻腔、口腔、气道有封闭色块底层，硬腭为紫色连续边界；填充放在舌头、牙齿后方，左右剖面分别切换，完整外观与对称透视时隐藏。色块代表腔体范围，不代表实心组织。该底层和外侧轮廓补面由网页生成，不烘焙进GLB/Blender。

48个教学条目提供口唇、舌位、气息与声带提示，以及对照音入口；通过“看慢动作→听示范音→我来试试”进行练习。自查清单不录音、不自动评分。示范音仍为本地合成音，详细教学口径及待完善问题见 [TEACHING-REVIEW.md](TEACHING-REVIEW.md)。

运行 `Blender -b --python build_teaching_preview.py`（在项目根目录）可另存儿童配色的 `phonetic-head-child-teaching.blend`，保留20元音时间轴，不覆盖原始模型。网页动态剖面、部位标签和教学卡不烘焙到Blender文件中。

人头使用原始解剖结构和接缝修补后的皮肤。左右拆分、分层透明度、半侧剖面、24 通道口型形变、播放进度与气流控制继续可用。

## 交互性能

透明度滑动按帧合并处理；只有透明/不透明模式跨界才使材质程序失效。加载阶段预编译两种模式，避免首次切换时集中编译。透明双面材质使用单次绘制；暂停且镜头不动时跳过网格、DOM 和 GPU 重绘。模型点选按包含形变范围的包围球排序，再用真实三角面求交，不用近似部位替代实际拾取。

`npm test` 验证形变、配色、透明状态和拾取正确性；`npm run test:ui` 验证页面与学习流程；运行本地服务后执行 `npm run test:model` 验证无卡通模型请求、左右透明度、静止不重绘、点选中文名称与慢动作回归。`window.renderSnapshot()` 提供只读绘制计数和材质版本诊断。

皮肤接缝由 `../repair_skin_seams.py` 修补：焊接、清理法线、局部体素重建、交界区域平滑与减面，重新打开唇缝并应用共享的连续皮肤形变场。输出独立的 `dist/assets/repaired-skin.glb`；修补步骤不改写输入 `phonetic-head.glb`。24 通道升级由人体导出脚本生成新的输入资产，再依次重建修补皮肤和实体内芯。参数及尺寸偏差见 `dist/assets/skin-repair-report.json`。

发音形变仍需专业语音教学人员验证。

## 实体截面与接缝

网页加载后由 `dist/sections.js` 提取各结构中央平面内侧 0.02 mm 的交线，三角化闭合轮廓并保留嵌套孔洞。肌肉、舌体及角色实体的半截面由真实三角面封口，封口沿原网格边插值同一套形变位移。气管、已标为 lumen 的通道和角色口腔空腔不作实心填充。复杂源网格中无法闭合的零碎轮廓不强行连接。

封口只在左右透明度不同时显示，继承所属结构的颜色、透明度和高亮；角色实体切面稍作提亮，与外皮区分。切换完整外观或对称透视时自动隐藏。该封口是在网页中生成的网格，不会改写原始 GLB 或 Blender 源文件。

左右半边的表面法线与形变法线在共同边界连续化，封口本身保留平面法线。皮肤接缝还进行了更宽范围的局部平滑，并重新导出形变法线，避免播放时恢复光照断层。

## 使用

### 三步小探索

模型下方的“开始小探索”依次引导观察、倾听和自查。看慢动作使用 0.65 倍的音频时间轴；正常示范默认 1 倍，避免再次拉慢已生成音频。每步由孩子主动开始，不自动循环或自动跳转。鼻音、爆破音和双元音分别提供气路、闭塞和滑动提示。观察重点按钮切换口唇外观或内部剖面，600 ms 平滑转场；拖动模型会接管镜头。

三颗星只记录“看完、听完、完成自查”，不检测发音、不请求麦克风。暂停、失败和切换音标不会误记完成，静音中断倾听任务；切换条目或刷新页面清空任务状态。教师仍需确认发音准确性。观察圈、声带条形动画为注意力提示，不是精确组织边界或采样波形。

“减少动效”默认跟随系统偏好，也可手动切换：关闭装饰动画、即时切换镜头，仍保留孩子主动播放的口型和气流教学动作。切到后台会暂停播放。手机端开始演示会把模型带入视野。

- 学习模式可选择 48 音标分类库、20 个元音口型、A–Z 字母名称。选中分类后，所有对应发音以按钮列表直接展开在下方，不再使用发音下拉框；元音口型模式分组显示 12 个单元音和 8 个双元音。点击即可选中，开始播放时从起点演示。字母名称同样展开 A–Z 及连续播放入口。进度条支持暂停定位，速度范围 0.2–3 倍，默认关闭循环。学习模式、音标分类和声线下拉使用自定义 listbox，支持方向键、Home/End、Enter、Esc、键入查找和点击外部关闭。
- “慢速跟读 · 声音同步”将速度设为教学基准的 0.65 倍，并打开声音；取消后恢复 1 倍。口型、逐词高亮、暂停和拖动均跟随同一音频时间轴。音频加载失败时停止并允许重试，不再播放独立的无声动画。
- 拖动旋转，滚轮或双指缩放；画布获得焦点后可用方向键转动。“口腔特写”直接靠近舌腭区域。
- “模型左半侧 / 右半侧”各自控制整个半侧的透明度。采用解剖左右：源模型 +X 为左，-X 为右，正面看时与观察者的左右相反。100% 表示完全透明。可一键交换。
- 皮肤、骨骼、肌肉、发音器官的层透明度叠加于半侧透明度，最终不透明度 = (1 - 半侧透明度) × (1 - 层透明度)。无需绑死为某一侧剖面。
- 点击模型或器官列表高亮目标，观察对应动作。橙色变化表示教学动画当前参与的肌群，不是肌电测量。
- 气流粒子和箭头沿口咽通道前进，暂停时停住；爆破音闭塞时无外流，释放时出现短促气流。气流可单独隐藏。

## 示范声音

老师词句示范默认 1× 正常语速，课堂支持 0.5×–1.5×（每步 0.05×）滑杆和六档快捷选择，播放中即时生效，本次课程切换章节保留手动选择；实验室速度滑杆和录音对比示范显示实际倍率。自己的录音保持 1× 回放。显示 1× 就是原录音的正常速度，没有隐藏减速。慢速跟读默认实际 0.65×，也可调整，不会重复放慢；音频保持音高，口型跟随音频时间轴。

提供英式男声、女声两套本地合成示范。48 个音标直接使用音素输入，26 个字母使用完整名称的音素序列；另有 A–Z 整段录音，共 150 个 WAV。字母名称、A–Z 及课程词句采用 Kokoro 神经语音（英式女声 bf_emma / 男声 bm_george），孤立音素保留 eSpeak NG 的明确音素输入；均为合成音，并非真人录音。播放无需语音服务或账户。

独立单元音以教学辨音为目的生成：除弱元音 /ə/ 外使用明确的重读输入；长元音采用 95、短元音采用 170 的引擎语速，突出持续段差异。/iː/ 与 /ɪ/、/uː/ 与 /ʊ/ 始终使用各自不同的音素，不通过重复、降调或拉伸同一个元音生成另一音。字母名称以 Kokoro 的 0.9 合成语速生成，不做后期时间拉伸。这些时长是示范设置，不是自然英语的固定比例；合成音质仍需语音教师试听校准。

点击“播放发音”同时播放声音和动作；“声音”可静音而保留动画。暂停和拖动会停止音频，切换条目会回到开头；播放中更换声线会从新声线开头继续。下载或播放失败会显示可重试状态。移动端同时保留当前音标说明。

速度使用 0.2–3 倍滑轨，精度 0.01 倍，拖动立即生效；切换声线或音标保留速度。音频启用保持音高，模型继续跟随音频实际播放位置；极慢或极快播放仍会受浏览器时间伸缩音质限制。

重建音频（仅构建时需要 Python 依赖）：

```sh
python3 -m venv .audio-venv
.audio-venv/bin/pip install espeakng-loader==0.2.4
bash build.sh all
npm run build:lessons
```

`build.sh natural` 首次需 Python 3.12（可用 `AUDIO_PYTHON` 指定路径）、Node 和 ffmpeg；下载并校验固定版本的本地模型，之后复用缓存。模型和 Python 环境不发送到浏览器。

音频来源及局限见 `dist/assets/audio/README.md`。声带形变与录音并非生物力学求解，教师使用前仍需校准音质与动作。


## 每日学习与语音教练

新增 rabbit、bird、duck、horse、lion、panda，全部保留字母音→单词→短语→完整句的路径。动物是课程情境形象，发音演示仍复用已有三维教学人头。

- 首页按本地日期提供下一课与到期复习、月历、连续学习天数和课程搜索。复习间隔为 1/3/7/14 天；10课完成后明确进入复习，不声称无限新课。
- 两项自查完成后即可打开回顾。今日打卡另外要求当天完整听过句子：听读日期随课程进度保存，刷新不会丢失；自查页可直接重听，先勾选再听也会自动更新。仅访问回顾不打卡，旧听读记录不计入今日；同一天同一课幂等。记录只保存在当前浏览器。
- 课堂、实验室、`practice.html` 可录音最多15秒，回听/听示范/删除。本地指标只有音量、停顿和时长参考；老师可人工给1–5分和鼓励语，绝不自动生成“标准”结论。
- `practice.html?mode=sing` 提供 A3 / 220 Hz 参考音与可靠有声片段基频估算，支持轻哼对比；是音高入门，不是完整歌曲或音准认证。
- beui.dev 的留白、细边框、字重层级用于教师实验室视觉参考；分类后的全部条目保持在下方展示。

### 可选 AI

将 `.env.example` 复制为本地 `.env`，配置 `AI_API_KEY`、`AI_BASE_URL`、`AI_CHAT_MODEL` 和 `AI_TRANSCRIBE_MODEL`，再运行 `npm start`。密钥只在 Node 进程；前端不保存、不回传密钥。不配置时，全部本地教学、录音和人工点评可用，在线教练明确显示未连接。

兼容接口需同时支持 `/audio/transcriptions` 与 `/chat/completions`。用户先同意再主动发送，或明确开启连续语音（有声后约1.2秒静音发送，15秒上限）；回复使用系统朗读，播完再开麦。随时结束，切后台/主题/本地音频动作都会取消会话。删除只清本地录音，不能撤回已发给服务商的数据；服务端不写入录音或转写日志。

在线结果的百分比仅为转写文字匹配度，不是发音分数。孤立音素禁用转写判分；AI不根据文字诊断舌位、音量或口音。真实服务调用和费用取决于本地配置；当前验证使用模拟上游，未使用任何用户凭据。

### 后续教学方向

先由英语教师校准新课发音与口型，再接经过验证的音素评测服务；对儿童语音、噪声、口音分别测误判率。之后可扩展自适应复习、故事对话与多天主题课程。唱歌沿“舒适发声→节奏→短旋律→歌曲”推进，先验证不同声区和麦克风的音高识别，不把一次音高估计当成歌唱评分。

验证命令：`npm test`、`npm run test:server`、`npm run test:ui`。浏览器测试需4173静态页及4174应用服务（或 `TEST_APP_URL`）；使用本机 Edge/Chrome，模拟麦克风音源但实际调用 MediaRecorder 与解码，不自动申请物理麦克风。

## 模型与动画

加载本地 V04 Blender 白模派生的 GLB，包含 268 个左右拆分网格。人体及两个角色各自覆盖 24 个非零几何控制通道；单个结构只携带与自身相关的通道，不为每块骨骼填充空形变。皮肤、口轮匝肌、颏舌肌、舌骨舌肌、咬肌/下颌及相关口周肌肉按各自区域和附着端权重联动。新增可编辑人体文件 `../phonetic-head-articulated.blend` 保留原 V04 白模。

元音修订：重新开放修补皮肤的唇缝，平滑唇缘并让下唇随下颌张开；圆唇集中在口周，角色口腔边缘与外皮一起收拢。完整外观隐藏表浅肌肉，剖面/透视仍按原透明度控制显示。内部填充随新皮肤重新生成。`phonetic-head-articulated.blend` 与 `character-heads.blend` 各有 20 段元音关键帧，每段 120 帧，30 fps，时间轴标记标出音标和例词。网页继续混合原有 24 个通道；Blender 动画使用同一份 `phonemes.js` 姿态数据。

按顺序重建：`export_interactive.py`、`repair_skin_seams.py`、`build_solid_core.py`；角色运行 `build_character_heads.py`。均使用本机 Blender `--background --python`。最后一步会把网页实际加载的修补皮肤、内部填充和解剖结构保存到人体 Blender 文件。用 `check_vowel_blender.py` 检查两份文件的关键帧，用 `node check-vowels.mjs` 检查 20 元音 × 3 头部、真实画布差异、慢动作和移动端。

这些形变由程序根据发音动作手工设定，不是肌肉力学求解。气流是口腔或鼻腔路径示意，不是 CFD；BreathPressure 仅代表教学用相对送气强度，其几何表现为轻微口周扩张和喉部位移，不是压强测量。Voice、GlottisClose 和 VocalTension 是独立的喉部形变，不合成真实音频，也不等于真实声带振动波形。示范音频是单独生成的本地合成音。已加入本地录音分析与人工点评；没有专业音素自动评分、歌词/歌曲音频对齐。

## 国内常见48音标教学集合

采用英式非卷舌教学口径的 44 核心音素：12 单元音、8 双元音、24 辅音；另单列 /ts/ /dz/ /tr/ /dr/ 四项连续辅音组合，共计 20 元音、28 辅音。这是“国内常见48音标教学集合”，并非唯一 IPA 划分，也不声称四个组合是所有英语分析中的独立音素。

保留传统 /ɪə eə ʊə/ 教学符号；现代英式口音中某些词已发生合流或单元音化。/r/ 为教材宽式记号，动画采用英语近音 [ɹ] 的后收舌形，不是颤音 [r]；实际英语 /r/ 也可采用舌体聚拢构形。A–Z 字母采用英式名称：R /ɑː/，Z /zed/，W /dʌbəljuː/。没有加入美式 zee 或卷舌 R 的切换。

`dist/phonemes.js` 保存每项 IPA、分类、示例词、说明、focus 和姿态轨迹。清浊对共享口腔姿态，通过 Voice/GlottisClose/GlottisOpen/VocalTension/BreathPressure 区分；鼻音降低软腭；双元音具有起止姿态；塞擦音和四个复合辅音具有闭塞与连续释放构形。字母名称只引用存在的核心音素。

连续时间轴使用 90 ms 对称协同过渡窗口、平滑插值和整段起止包络，中间音素不归零。原四音入口及独立曲线已移除，全部使用统一音素库。模型进度跟随音频 currentTime，支持暂停、拖动、0.2–3× 倍速和循环。字母内部的音素比例仍是教学编排，不是语料强制对齐；A–Z 连播按实际字母音频区间切换模型，字母间有短暂停顿。尚未对任意高权重组合进行碰撞、软组织体积守恒或接触约束求解，尤其舌齿接触、/r/、唇齿音和角色比例需要语音教师及三维解剖人员校准。通过测试表示数据和几何链路有效，不代表临床或生物力学精确。

## 启动与检查

在本目录运行 `npm start`，或用 `PORT=4174 npm start` 指定空闲端口。需要 Node 22+；纯静态预览仍可用 `python3 -m http.server 4173 --bind 127.0.0.1 --directory dist`，但不提供 AI 接口。网页及 three.js 均为本地资产，无 CDN 依赖。运行时不需要构建。

`npm test` 验证 48/20/28 数量、IPA 唯一、26 字母引用、清浊与鼻音/双元音/塞擦音行为、相邻过渡、150 个音频的有效 PCM/时长/校验和、字母表录音拼接，以及人体和每个角色的全部 24 个非零 GLB morph 位移（含稀疏数据）。同时检查修补皮肤、内芯、分层透明度与截面材质。
